# Shared Exceptions

## Objetivo

Centralizar todas las excepciones utilizadas por Tenorio3G Platform.

## Responsabilidades

- Definir excepciones personalizadas.
- Facilitar el manejo de errores.
- Unificar mensajes del sistema.

## No debe hacer

- Registrar eventos.
- Mostrar interfaces.
- Ejecutar lógica de negocio.
