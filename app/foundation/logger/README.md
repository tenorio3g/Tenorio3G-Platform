# Foundation Logger

## Objetivo

Registrar todos los eventos importantes de Tenorio3G Platform.

## Responsabilidades

- Registrar eventos.
- Registrar advertencias.
- Registrar errores.
- Registrar eventos críticos.
- Facilitar auditoría.

## No debe hacer

- Mostrar interfaces.
- Ejecutar lógica de negocio.
- Modificar datos.
