# Assets Domain

## Propósito

El dominio Assets representa todos los activos físicos y lógicos de la organización.

Su responsabilidad es conservar la identidad, historia, conocimiento técnico, estado operativo y seguridad de cada activo durante todo su ciclo de vida.

Este dominio constituye el núcleo operativo de Tenorio3G Platform.

---

## Principios

- Un activo es un expediente vivo.
- Toda intervención genera conocimiento.
- La seguridad forma parte del activo.
- Todo activo genera eventos.
- Toda información debe ayudar a tomar decisiones.
