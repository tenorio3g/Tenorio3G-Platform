Tenorio3G Design System
Principios
1. La información importante debe verse primero.

Nunca obligar al usuario a leer para encontrar un dato crítico.

2. Menos clics.

Toda acción frecuente debe estar visible.

3. Consistencia.

Una tarjeta de Materiales debe sentirse igual que una de Herramientas.

4. Industrial.

El diseño debe priorizar rapidez y claridad sobre efectos visuales.

5. Escalable.

Cada componente debe poder reutilizarse en cualquier módulo.
