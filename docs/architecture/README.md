# Tenorio3G Architecture

Bienvenido a la documentación de arquitectura de Tenorio3G Platform.

## Objetivo

Mantener un diseño consistente, escalable y fácil de mantener.

## Principios

- Domain Driven Design (DDD)
- Clean Architecture
- SOLID
- Desarrollo incremental mediante Micro Sprints
- Pruebas unitarias antes de integrar cambios
