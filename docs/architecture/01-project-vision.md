# Project Vision

## Misión

Crear una plataforma modular para la administración del mantenimiento industrial y la preservación del conocimiento técnico de la organización.

## Objetivos

- Centralizar la información de los activos.
- Registrar el historial de mantenimiento.
- Administrar órdenes de trabajo.
- Gestionar inventario y refacciones.
- Facilitar la toma de decisiones mediante indicadores.
- Preservar el conocimiento técnico generado por el personal.

## Filosofía

El conocimiento técnico es uno de los activos más valiosos de una empresa.

Si no se documenta, se pierde.

Si se preserva y comparte, se convierte en una ventaja competitiva.
