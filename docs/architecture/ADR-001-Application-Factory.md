# ADR-001
## Uso de Application Factory

### Estado

Aceptado

### Contexto

Se requiere una arquitectura que permita crecer de forma modular.

### Decisión

Se utilizará el patrón Application Factory de Flask.

### Consecuencias

- Facilita las pruebas.
- Permite múltiples configuraciones.
- Favorece una arquitectura modular.
- Evita dependencias globales.
