# Tenorio3G Platform

## Nuestra misión

Transformar la experiencia diaria de las personas en conocimiento permanente para la organización.

## Nuestra visión

Construir una plataforma que ayude a las empresas a conservar, organizar y aprovechar su conocimiento operativo.

## Nuestros principios

- Todo evento deja evidencia.
- Todo conocimiento debe poder encontrarse.
- Todo módulo tiene una responsabilidad.
- La arquitectura debe durar más que la tecnología.
- El software debe adaptarse a la empresa, no la empresa al software.
